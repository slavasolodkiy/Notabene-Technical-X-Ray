## Reading discipline

- **VERIFIED FACT** means the public commit object and diff were inspected.
- **ARCHITECTURAL INTERPRETATION** is explicitly inferential and is not a vendor statement.
- A commit proves that a public repository changed. It does not prove deployment, migration completion, production behavior, performance, or deprecation unless separately documented.
