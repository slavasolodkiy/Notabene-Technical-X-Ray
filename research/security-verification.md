Run `node scripts/scan-secrets.mjs` for the raw research, corpus, and current public tree. Run `node scripts/scan-secrets.mjs artifacts/notabene-xray/public` for the publishable assets alone. Run `node scripts/export-portable.mjs --output /tmp/notabene-portable-review` (choose a fresh directory), then `node scripts/scan-secrets.mjs /tmp/notabene-portable-review`. Exit status is 0 for no matches, 1 for matches, 2 for an incomplete scan. Output contains only paths, line numbers, rule types, and counts, never matched values. The exporter itself fails closed and removes its newly generated output when the exported tree's scan fails.

Do **not** treat the checks below as final approval: other agents are rebuilding generated public outputs. Repeat these commands against their final output and inspect the redacted findings before publishing. Do not paste any candidate secret into issues, logs, chat, or documentation.

## Limits

The local scanner is heuristic, not proof of absence: it tests common credential signatures and assignments, skips binary/NUL files, `.git`, `.local`, `.yarn`, `node_modules`, caches, build output, and `.portable-export`; it does not inspect git history, external links, live remote pages, non-ZIP archives, or dependency/vendor content. ZIPs are scanned including nested ZIPs to depth 3; size limits are 32 MiB per file/member and 128 MiB aggregate extracted archive data. Oversized/unreadable/symlink items yield exit 2 rather than a silent clean result. Non-standard or split credentials, encoded/encrypted values, and new patterns may evade detection. A clean scan does not establish the redistribution rights of downloaded research.
